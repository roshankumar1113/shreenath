Shreenath Das - Portfolio (source code)

Files
- index.html      : full website (HTML + CSS + JS in one file)
- assets/photo.jpg: your photo (replace with a new one, same name)

Run
- Double-click index.html (internet needed for fonts and libraries), or
- python3 -m http.server  then open http://localhost:8000

Libraries (loaded from CDN): GSAP + ScrollTrigger, three.js r128, vanilla-tilt, Lenis, Google Fonts (Bricolage Grotesque, DM Sans, Material Symbols).

Deploy: upload the folder to Netlify, Vercel or GitHub Pages (drag and drop works).
Edit text: search the content in index.html. Change colors: the :root variables (--o is the orange).
